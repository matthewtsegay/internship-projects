

# Simple Python Chatbot

This is a basic chatbot created using Python. It uses a function, a `while` loop, and `if-else` statements to respond to specific user inputs.

##  How It Works

* The chatbot greets the user.
* It continuously asks for input using a `while` loop.
* Based on what the user types, it responds with pre-defined replies using `if-elif-else` statements.
* The chat ends when the user types `"quit"`.

##  Features

* Responds to:

  * `hello`
  * `how are you`
  * `bye`
* Exits when user types `quit`
* Handles unknown inputs with a default message

##  Requirements

* Python 3 installed

##  How to Run

1. Save the chatbot code in a `.py` file (e.g., `chatbot.py`).
2. Open a terminal or command prompt.
3. Run the program using:

```bash
python chatbot.py
```
